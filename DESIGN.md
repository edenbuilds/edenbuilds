# Design System

## Visual Theme

**Mood:** Founder operating memo. Near-black canvas, ivory type, emerald accent. Premium software company, not personal portfolio.

**Aesthetic lane:** Infrastructure-product restraint. Architectural grid, sharp hierarchy, deliberate spacing. No playful ornament.

## Colors

| Role | Hex | Notes |
|------|-----|-------|
| bg | `#050607` | Pure near-black |
| surface | `#0c1512` | Slight emerald-tinted panel |
| ink | `#f5f2ea` / `#e8e4dc` | Ivory hierarchy |
| muted | `#8b949e` / `#6e7681` | Secondary labels |
| accent | `#10b981` | Restrained emerald (≤10%) |
| rule | emerald → ivory fade | Section dividers |

Strategy: **Restrained**. Accent is scarce and intentional.

## Typography

GitHub-constrained. Prefer weight and spacing over font choice.

- Display: EDEN wordmark, tracked caps
- Body: default GitHub prose, short paragraphs
- Meta: monospace for operating-memo labels in SVG
- No emoji section grammar; badges used sparingly

## Components (README)

- Hero SVG with monogram + memo card
- Flat-square shields (role / focus / mode)
- Stack icon rows + rationale tables
- Curated systems tables by function
- Collapsible capability map (`<details>`)
- ASCII glance panel
- Quiet closing contact line

## Layout

One composition. Strong horizontal rules. Curated sections over exhaustive lists. Stack expands; systems stay selective.

## Do / Don't

**Do:** dark premium palette, SVG logos, why-chosen stack rationale, operator voice  
**Don't:** em dashes, emoji walls, purple glow, freelancer tone, repo-link catalogues, vibe-coder language
