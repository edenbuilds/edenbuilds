# Greyhound DPDP

Use this skill for India DPDP review.

## Check

- Notice and consent
- Purpose limitation
- Data retention and erasure
- User rights handling
- Significant data fiduciary style controls where relevant
- Security safeguards
- Processor contracts and cross-border handling

## Output

- DPDP risk summary
- Evidence-backed gaps
- Recommended remedial actions
- Follow-up verification steps
