# Greyhound Performance and Stress

Use this skill for performance measurement and load validation.

## Measure

- Lighthouse and Core Web Vitals
- Render blocking and hydration cost
- Bundle size and duplication
- Network waterfalls and caching
- Slow interactions and long tasks
- API latency and throughput

## Stress Test

- Use realistic concurrency.
- Prefer small representative scenarios before full-scale load.
- Separate browser-side and API-side bottlenecks.
- Capture p95/p99 latency where possible.
- Stop when the system shows instability or error amplification.

## Output

- Baseline metrics
- Hot paths
- Bottlenecks
- Load test assumptions
- Fix priority list
