# Greyhound UI/UX Audit

Use this skill for visual and interaction quality review.

## Focus Areas

- Layout consistency
- Typography hierarchy
- Spacing and rhythm
- Color contrast and brand alignment
- Accessibility and keyboard flow
- Responsive behavior across breakpoints
- Motion, transitions, and perceived polish
- Framer-specific implementation quality

## Process

1. Inspect the live UI.
2. Compare observed behavior against the intended system.
3. Note friction points and inconsistencies.
4. Prioritize issues by severity and user impact.
5. Include screenshots or precise UI references.

## Audit Output

For each issue, include:
- Location
- Severity
- Evidence
- Why it matters
- Suggested fix

## Guardrails

- Do not call a design "bad" without evidence.
- Distinguish preference from accessibility or usability defects.
- Verify breakpoints, empty states, and error states.
