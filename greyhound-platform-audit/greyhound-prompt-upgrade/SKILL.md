# Greyhound Prompt Upgrade

Use this skill when the platform itself includes prompts, instructions, or agent behavior that should be improved.

## Check

- Prompt clarity
- Instruction ordering
- Missing constraints
- Weak failure handling
- Bad defaults
- Vague tool routing
- Duplicate or conflicting steps

## Output

- Revised prompt
- Better operating instructions
- Suggested slash commands or templates
- Behavior risks
- Minimal replacement text
