# Example Workflow

Example: full audit of an authenticated Framer dashboard.

1. Confirm target, scope, and auth method.
2. Open the dashboard with the browser agent.
3. Crawl key routes, panels, and settings surfaces.
4. Capture UI, accessibility, console, and network evidence.
5. Run a performance pass on the heaviest pages.
6. Run a security and infra review on exposed configs and dependencies.
7. Rank findings and summarize the fastest high-value fixes.
8. If asked, generate patches and re-audit.

Example outputs:
- Executive summary
- Evidence table
- Prioritized fix list
- Patch or diff set
- Re-audit result
