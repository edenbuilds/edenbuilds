# Validation Plan

Use these checks to verify the pack works:

1. Trigger the master skill with a live platform audit request.
2. Confirm the browser module collects real evidence.
3. Confirm UI, performance, security, and Framer modules can be routed independently.
4. Confirm remediation produces a concrete diff or patch plan.
5. Confirm re-audit reports whether the issue remains.

Pass criteria:
- Evidence attached to findings
- Secrets never echoed
- Scope respected
- Output is actionable
- Fixes are verifiable
